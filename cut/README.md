# スイング・ラリー自動カット（iPhone だけで動く版）

iPhone の Safari で開くだけで使える、ゴルフのスイング切り抜き／テニスのポイント間カットです。
Mac やサーバーは不要で、**動画は iPhone の外に送信されません**。

公開先（GitHub Pages）: `https://air-tomo.github.io/cut/`

## 使い方

1. 上部で「⛳ ゴルフ練習」か「🎾 テニス試合」を選ぶ
2. 動画を選んで「読み込んで検出する」
   - 長い動画は「写真」アプリの共有 →「"ファイル"に保存」してから「ファイル」で選ぶと、変換待ちがなく画質もそのまま
3. 確認・調整
   - 各区間の ▶ で元の動画を再生、チェックを外すと書き出さない
   - 「開始」「終了」の ±0.5 で区間を微調整
   - 「つなげて再生」で書き出し後のイメージを確認
   - 「検出の設定」を変えるとその場で検出し直す（モードの切り替えも、動画を読み直さずにできる）
4. 「書き出す」→「写真に保存・共有」→「ビデオを保存」

## しくみ

- **検出**: 動画から AAC 音声を少しずつ取り出して Safari でデコードし、打球音（10〜20ms の鋭い衝撃音）を探す。
  ゴルフは打球の前後（3 秒前〜2 秒後）、テニスは打球の間隔が 4 秒以内の打球をラリーとしてまとめ、
  サーブの 2.5 秒前〜最後の打球の 2 秒後を残す。方法と初期値は `golf-swing-app/`（Mac 版）と同じ
- **書き出し**: 再エンコードせず、映像・音声データをそのままコピーして1本の動画にする。
  画質が落ちず速い（テスト環境で 1 時間の動画を約 2 秒）。そのため各区間の開始・終了は
  キーフレーム（iPhone の動画では通常 1 秒前後ごと）の位置に合わせて少し広がる
  - B フレーム・HEVC のオープン GOP にも対応（つなぎ目の CRA を BLA に変換し、表示できない RASL フレームを除く）
  - 縦向き・HDR（Dolby Vision）の情報もそのまま保たれる
- **保存**: 書き出し中の動画はブラウザ内の保存領域（OPFS）に少しずつ書くので、大きな動画でもメモリ不足になりにくい。
  プライベートブラウズでは保存領域が使えないため、メモリ上で作る（短い動画向け）

## 動作環境

- iOS 16.4 以降の Safari（iOS 26 推奨）
- iPhone で撮影した MOV / MP4（AAC 音声）。それ以外の音声形式は 800MB までの動画のみ

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `app.js` | 画面の操作、音声の取り出し、プレビュー |
| `detect.js` | 打球音の検出、スイング／ラリーの区間計算 |
| `mp4.js` | MP4 / MOV の読み込みと、再エンコードなしの書き出し |
| `worker.js` | 書き出し処理（OPFS へ書き込む Worker） |
