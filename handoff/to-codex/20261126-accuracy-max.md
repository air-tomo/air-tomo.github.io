# ボール検出・落下判定・切り出しの精度を、使える公開データ全部で上げる

オーナーの希望:「精度は極限まで。web にある動画を全部使って」。
ただし **ライセンスで学習利用が認められたデータだけ** を使う。YouTube などの動画を勝手にダウンロードして学習に使わない
（利用規約・著作権違反。アプリを売るので後で問題になる）。迷うデータは使わず、報告に「候補・理由」として書く。

## 1. データを集める（ライセンスを必ず記録）
- 調べて、学習に使えるものを全部入れる。各データの URL・ライセンス・使った枚数を `golf-swing-app/tools/court3d/DATASETS.md` に表で書く。
- 候補（自分で探して増やしてよい）:
  - Hugging Face BrianGuo/Tennis_Data（MIT、前回使用。SwingVision の重ね表示がある切り抜きは除外）
  - TrackNet のテニスデータセット（論文の公開データ。ライセンスを確認）
  - WASB（Widely Applicable Strong Baseline）のテニス・バドミントン等のデータ（ライセンス確認）
  - Roboflow Universe のテニスボール検出データ（CC BY 4.0 などのものだけ）
  - Kaggle のテニス追跡データ（ライセンス確認）
  - オーナーの Google ドライブ「テニス動画」の試合動画（自分の動画なので可）
- 公開リポジトリに動画・画像・学習データ・大きな重みを commit しない。データと重みは Mac か Google ドライブに置く。

## 2. 学習
- `train_crops.py` / `make_crops.py`（SmallNet）を基本に、データを全部まとめて学習。高い位置・低い位置・横から・屋内外を混ぜる。
- 端末で動く大きさを守る: ONNX は 3 MB 以下、iPhone の WebGPU で 1 コマ 15 ms 以内が目安。超えるなら大きいモデルと小さいモデルの両方を作り、差を報告。
- 拡張: 明るさ・ぼけ（動きぶれ）・JPEG 劣化・縮小（遠くの小さいボール）・左右反転。

## 3. 評価（教師モデルとの一致ではなく、人が確かめた正解で）
- 学習に一度も使っていない動画で測る。最低限:
  - `tests/data/IMG_0131_bounce_bottoms.json`（60fps で目で付けたバウンド位置）→ 落下位置のずれ（中央値・90%）
  - オーナーの高い位置の動画から 300 コマ以上、手でボール位置を付けた正解を作る（`tests/data/` に座標の JSON だけ置く。画像は置かない）→ F1（4 px 以内）
- 前回のモデル（F1 0.906、TrackNet 一致 47.7%）と並べて表にする。
- `bash tests/run_all.sh` が ALL OK のままであること。
