# コート・ボールの 3D 解析（試作）

固定カメラの試合動画から、コートの位置合わせ → ボール追跡 → サーブの落下地点・球速を出す試作。
IMG_0131（iPhone 14 Pro、1920×1080・約 60fps、地面から約 0.7m・手前ベースラインの約 6m 後ろ）で作った。

## 手順

```bash
# 1. 背景（選手のいない中央値画像）を作って白線を検出
python3 lines.py bg.png c                 # c_segs.npy, c_lines.png
python3 court.py c_segs.npy bg.png lines.json
python3 homog.py lines.json bg.png court_fit.png      # 地面の射影変換 (court_fit.png.H.npy)
python3 camera.py court_fit.png.H.npy cam.npz          # 焦点距離・カメラ位置
python3 refine.py cam.npz court_fit.png.H.npy cam3.npz 505 8   # ネットポスト・ネット中央・奥のベースラインで補正
# 2. サーブ 1 本（打球音の時刻を渡す）
python3 serve.py video.mov cam3.npz x 527.63
```

## しくみ

- **位置合わせ**: 白線（細く明るい線）を Hough 変換で拾い、ベースライン・サービスライン・サイドラインを識別して射影変換を求める。
  主点＝画像中心・正方画素として焦点距離とカメラ位置を出し、ネットポスト（高さ 1.07m）・ネット中央（0.914m）・
  奥のベースラインの行で補正する（`refine.py` の画像座標は IMG_0131 で読み取った値）
- **ボール**: 3 フレーム差分の小さな黄色い塊（選手の大きな動きの近くは除く）を、ほぼ等加速度でつながる点列として追跡
- **サーブ**: 打球音の時刻を打点とし、空中の点列に重力・空気抵抗つきの 3D 軌道を当てはめ、地面 (z=0) まで延長して落下地点とする。
  打点は「手前ベースラインの少し後ろ・高さ約 2.6m」を弱い事前条件にしている

## 精度と課題

- カメラが低い（ネットより低い）ので、奥のコートは数画素に圧縮される（奥のベースラインで 1 画素 ≒ 0.8m）。
  奥行きは軌道全体の当てはめで補うが、位置合わせの数画素の誤差で 1〜2m ずれうる
- 打点付近は選手の体と重なってボールを拾えないことが多く、14 本中 5 本しか軌道が取れなかった
- 実際の落下地点（正解）との照合はまだ。高さ 2〜3m から撮った動画なら精度は大きく上がる
