# ゴルフスイング自動切り抜き／テニス ポイント間カット

**打球音**を手がかりに動画を自動でカットし、**1本の MP4** にする Web アプリです。画面上部で切り替えます。

- **⛳ ゴルフ練習**: 練習動画からスイングだけを切り出してつなげる
- **🎾 テニス試合**: 試合動画からポイント間の待ち時間を取り除き、ラリーだけをつなげる

> Mac なしで iPhone だけで使いたい場合は、Safari で動く版 [`cut/`](../cut/)（`https://air-tomo.github.io/cut/`）を使ってください。

- 日本語 UI / iPhone Safari 対応（写真ライブラリから直接アップロード可）
- 切り出し範囲のデフォルトは **打球の 3 秒前〜2 秒後**（画面で変更可）
- アップロード・検出・切り出し・結合の進捗をパーセント表示
- iPhone の HEVC・縦向き・HDR 動画に対応（HDR は SDR の H.264 に変換）

## 必要なもの（Mac）

| ソフト | 確認コマンド | ない場合 |
| --- | --- | --- |
| Python 3.9 以上 | `python3 --version` | `xcode-select --install` または `brew install python` |
| FFmpeg | `ffmpeg -version` | `brew install ffmpeg` |
| Homebrew（FFmpeg を入れる場合） | `brew --version` | https://brew.sh の手順でインストール |

## 起動手順

```bash
cd golf-swing-app
./start.sh
```

初回は `.venv`（Python 仮想環境）の作成とライブラリ（Flask / waitress / numpy）の
インストールを自動で行います。手動で行う場合は次のとおりです。

```bash
cd golf-swing-app
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

起動するとアクセス用の URL が表示されます。

```
  この Mac から : http://localhost:8000
  iPhone から   : http://192.168.x.x:8000
  (または)      : http://<Macの名前>.local:8000
```

終了は `Ctrl + C` です。

## iPhone からアクセスする

1. iPhone と Mac を**同じ Wi-Fi** に接続します。
2. 起動時に表示された `http://192.168.x.x:8000` を iPhone の Safari で開きます。
   - Mac の IP アドレスは `ipconfig getifaddr en0` でも確認できます。
3. 初回起動時に macOS から「"python3" へのネットワーク受信接続を許可しますか？」と
   表示されたら **「許可」** を選んでください（ファイアウォールが有効な場合）。
   - 誤って拒否した場合: システム設定 → ネットワーク → ファイアウォール → オプション で
     python3 を「受信接続を許可」に変更します。
4. つながらない場合は、ゲスト Wi-Fi や「プライバシー分離」機能のあるルーターでないか確認してください。

> **セキュリティについて**: アプリは認証なしで同じネットワーク内の端末からアクセスできます。
> 自宅など信頼できる Wi-Fi でのみ使い、公共 Wi-Fi では `./start.sh --host 127.0.0.1`
> （この Mac からのみ接続可）で起動してください。インターネットには公開されません。

## 使い方

1. 「タップして動画を選択」から練習動画を選ぶ
2. 必要に応じて設定を変更
   - **打球の前／後**: 切り出す秒数（デフォルト 3 秒／2 秒）
   - **検出感度**: スイングを見逃すときは上げる、関係ない音を拾うときは下げる
   - **最短の打球間隔**: これより短い間隔の音は同じスイングとして扱う
3. 「切り抜きを開始」→ 完了するとプレビューと「MP4 をダウンロード」が表示されます
4. iPhone では Safari の「ダウンロード」から共有ボタン →「ビデオを保存」で写真アプリに保存できます

処理結果はアプリフォルダの `jobs/` に保存され、24 時間後に自動で削除されます。

## テニス ポイント間カット

### しくみ

ポイントはサーブから始まります。ポイント間は通常 20〜25 秒（プロのルール上限は 25 秒、四大大会は 20 秒）、
ラリー中の打球間隔は 1〜3 秒なので、打球音の間隔と並び方からポイントを組み立てます。

1. 打球音（10〜20ms の鋭い衝撃音）をすべて検出する
2. 間隔が「ラリーの打球間隔」（初期値 5 秒）以内の打球を1つのラリーにまとめる
3. **サーブ前のボールつき**（1 秒未満のリズムで 2 回以上続き、トスの間を空けて、より大きなサーブの音が来る）を除き、
   最初の打球をサーブとする。ポイント間が短く、ボール拾い・足音・ボールつき（1〜2 秒おきの小さな音）で
   前のラリーとつながった場合は、大きな打球（手前の選手）が 9 秒以上なかったあとの大きな打球で区切る
4. **フォルト**（サーブだけの打球）のあと 12 秒以内（「セカンドサーブまで」）にサーブがあれば、同じポイントにまとめる。
   フォルトとセカンドサーブの間の待ち時間は除く。1st と 2nd は同じ選手が同じ場所から打つので音の大きさがほぼ同じ。
   セカンドサーブより 3dB 以上小さい音（サーブ直前のボールつき、隣のコートの打球）はフォルトとせず取り除く
5. 打球数が「最少打球数」（初期値 2）未満は物音として除外。ただしサーブ並みに大きい1打はエースなどとして残す
6. 各サーブの **1.5 秒前**（トス）から最後の打球の **2 秒後**までを残す。間が 3 秒未満の区間はつなげて細切れを防ぐ
7. 書き出した MP4 には **ポイントごとのチャプター** が付き、QuickTime 等で頭出しできる

### 長い試合動画はコマンドで処理するのがおすすめ

数 GB ある試合動画は、アップロードせずに Mac 上で直接処理できます。

```bash
cd golf-swing-app
.venv/bin/python cli.py tennis ~/Movies/match.mp4 --list   # まず検出結果だけ確認
.venv/bin/python cli.py tennis ~/Movies/match.mp4          # match_cut.mp4 を書き出し
```

主なオプション: `--sensitivity 7`（感度）、`--pre 3` / `--post 2`（前後の秒数）、
`--max-gap 5`（ラリーの打球間隔）、`--min-hits 3`、`--no-serve-only`、`-o 出力.mp4`

Mac では GPU（VideoToolbox）で書き出すので、長い動画でも比較的速く処理できます
（使えない場合は自動でソフトウェア処理に切り替わります）。

### うまくいかないとき

| 症状 | 調整 |
| --- | --- |
| ラリーの途中で切れる | 「ラリーの打球間隔」を 5〜6 秒に、または感度を上げる |
| 奥側の選手の打球を拾えずポイントが欠ける | 感度を上げる（7〜8） |
| ポイント間の球出し・ボール拾いが残る | 「最少打球数」を 3 に上げる |
| 隣のコートの音でポイント間が残る | 感度を下げる |
| サーブの動作が切れる | 「サーブの前」を 2〜2.5 秒に |
| フォルトとセカンドサーブが別のポイントになる | 「セカンドサーブまで」を長くする |

撮影はコート後方のフェンス際など、両選手の打球音が入る位置が向いています。

## 動作確認用のテスト動画

打球音に似た音を 5 回含むテスト動画（iPhone と同じ HEVC・縦向きの .mov）を作れます。

```bash
.venv/bin/python tools/make_test_video.py test_videos/test.mov
```

アップロードすると 0:07、0:19、0:31、0:44、0:55 の 5 スイング（合計 25 秒）が出力されます。

テニス用には、ラリー・ボールのバウンド・サーブ前のボールつき・フォルト・エース・話し声・
隣のコートの音を含む約 6 分の試合風動画を作れます（正解のポイント区間を `.json` に保存）。

```bash
.venv/bin/python tools/make_tennis_test_video.py test_videos/tennis.mp4
.venv/bin/python cli.py tennis test_videos/tennis.mp4 --list   # 14 ポイント、6:34 → 2:26
```

## 検出のしくみ

1. FFmpeg で音声をモノラル 22.05kHz に変換
2. 高域を強調した約 5ms ごとの音量 (dB) を計算
3. 周囲 2 秒の中央値より大きく、かつ 15ms 以内に急激に立ち上がる音を打球とみなす
4. 「最短の打球間隔」内の候補は 1 つにまとめ、最も大きい点を打球時刻とする
5. 各打球の前後を H.264/AAC で切り出し、FFmpeg の concat で 1 本に結合

打ちっぱなしで隣の打席の音を拾う場合は、検出感度を下げるか、iPhone を自分の近くに置いて撮影してください。

```
├── cli.py              コマンドラインで処理（長い動画向け）

└── start.sh            Mac 用起動スクリプト
```
